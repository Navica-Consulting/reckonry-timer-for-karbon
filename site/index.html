Reckonry Timer for Karbon

Karbon blocked this extension.

Reckonry Timer started, switched, and paused the Karbon timer as you moved through your day. Karbon told us it goes against Karbon's terms, so we removed it from the Chrome Web Store. Please don't install or run a copy of it.

We'd still like a timer that follows your work, so we asked Karbon to build one. If you would too, vote for the feature idea in the Loft, Karbon's community.
